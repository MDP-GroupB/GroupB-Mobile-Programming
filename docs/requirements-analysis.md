## 1.2 Additional Features

We propose two features beyond R1 to R6. Only these two are included, so that each can be built and tested properly.

**Feature 1: Configurable event reminders (priority 1).** This feature is for students. In Notification preferences, a student turns event reminders on or off and chooses when they arrive (1 hour or 1 day before the event). The phone then shows a notification, and tapping it opens the booking, where the attendance pass can be opened. The value is that students forget fewer bookings, so fewer places go empty and fewer students miss the points they planned to earn. Clubs also benefit from better turnout. The scope is limited to reminders for booked events with simple time choices, and reminders are removed automatically if the booking is cancelled. General or marketing messages are out of scope, and event change or cancellation notices stay in the core communication flow. The feature has two limits. A phone with no connection cannot learn about a cancellation straight away, and reminders only appear if the student allows notifications on their device.

**Feature 2: Focused club attendance analytics (priority 2).** This feature is for club event managers. After an event, the manager can see the number of confirmed bookings, the verified attendees, the records received but still pending, and the attendance rate. The attendance rate is verified attendees divided by confirmed bookings at the start of the event, multiplied by 100. For example, 60 verified attendees from 80 bookings gives 75%. The value is that clubs can compare turnout between events and plan future capacity from real data instead of paper sheets. The scope is limited to totals and rates for each event, shown only to managers of that club. Charts across many events, reports on individual students and data exports are out of scope. The figures are labelled “Provisional” while scanner records are still outstanding or under review, because the system cannot count records that are still stored only on an offline scanner. If an event has no confirmed bookings, the rate shows “N/A”.
